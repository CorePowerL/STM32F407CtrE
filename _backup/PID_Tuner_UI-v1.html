PID 控制律（取自 main.c）

u = Kp·e + Ki·∫e·dt + Kd·(de/dt)
采样周期 dt = 100ms；转速低通滤波 0.7·旧 + 0.3·新
积分限幅 ∫e ∈ [-50, 50] · 输出限幅 u ∈ [-100, 100]%
编码器分辨率 11线 × 4倍频 × 30减速 = 1320 脉冲/转

引脚映射（motor.h / encoder.h）

  • M1 方向 IN1=PA2 · IN2=PA3　PWM ENA=PB0 (TIM3_CH3)
  • M2 方向 IN1=PA6 · IN2=PA7　PWM ENB=PC6 (TIM8_CH1)
  • 编码器 M1 A=PA0 B=PA1 (TIM2)
  • 编码器 M2 A=PB6 B=PB7 (TIM4)
  • 触摸 XPT2046 · 屏 SSD1963 via FSMC

按键行为

Target ±10 (0~250) Kp ±0.1 Ki/Kd ±0.05 START/STOP 启停当前电机 STEP 目标 100↔200 阶跃 RESET Kp=2.0 Ki=0.50 Kd=0.20
本页为 Core/Src/pid_screen.c 的 1:1 交互仿真：布局坐标、配色、按钮逻辑、PID 算式、波形（100 点 × 100ms = 10s 窗口，Y 轴 -50~250 rpm）均与固件一致。电机为一级惯性模型（含编码器噪声），用于可视化闭环响应。
